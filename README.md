# Founder Skills

**A practical skill system for founders.**

Founder Skills is a modular, evolving collection of practical capabilities for people building and leading businesses. Each capability is an independent module. Only implemented modules appear in this repository; future categories are not pre-created.

## Available skills

- [Communication](communication/README.md) — turn ideas, knowledge, and experiences into clear, structured, confident spoken communication.

## How to use

Start with the Communication quick start. Study a framework when needed, execute an individual skill for a specific bottleneck, then follow a workflow and evaluate the outcome. AI can coach and organize thinking, but should not invent the speaker's beliefs or replace their judgment.

**Status:** v0.1 — first module. Documentation and exercises; not a claim of validated training outcomes.
